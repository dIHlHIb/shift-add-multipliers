# 一个 AI 做研究的实验：移位加法乘法器

我想看看，现在的 AI 拿到一个研究目标、几乎没人插手时，能做到什么程度。选题、推导、代码、论文和 Lean 证明都是 OpenAI Codex 做的。Claude（Anthropic）一路做对抗审查，挑出了好几处真错误。还没有懂行的人类专家看过。我不主张这些结果有多新、多重要，这个仓库只是记录两个模型大约两天里做出了什么。

研究的是：硬件里用移位和加减法去乘固定常数，最少要几次加减。

分两部分，先后完成：

- [中间常数要留多少位？](width-bounds/) 要同时算出 m 个固定倍数，预算是 m+1 次加减。把常数中的 2 因子去掉，设目标最多有 w 位。只要这个预算够用，搜索到 2w 位就够了。当 w ≥ 16 时，有些输入至少得搜到 2w−9 位。这两个界都在 Lean 里证明了。
- [实际电路能省几次加减？](dsp-coefficients/) Arm 的九张 Q15 FFT 表去重、归一化后有 2,044 组。我们算出了每组和另外 83 个滤波器基准的最少加减次数。把中间数卡在目标位宽，只有一组 FFT 系数要多用一次加减，83 个滤波器都不受影响。里面有 29 个可以直接拿来试的 Verilog 电路。

每个文件夹里都有自己的说明、论文和 Lean 工程。

仓库中自己写的部分采用 GPL-3.0-only。第三方材料的来源和许可见[理论篇](width-bounds/THIRD_PARTY.md)和[电路篇](dsp-coefficients/THIRD_PARTY.md)。
