# Matched hardware comparison

The first hardware test let the six-gate search choose new parent nodes while Hcub kept its original wiring. The comparison below applies the same rewiring rules to both sides. It uses the same 29 pairs from the 128-point Arm Q15 FFT table, the same ABC flows, cell library, input width and exhaustive functional checks.

1. **Matched label and mapping budgets.** Read Hcub trials in seed order and the bounded list of six-gate solutions in its original search order. For each side keep the first occurrence of each distinct set of intermediate labels, represented by its original topological order. Remove labels unused by Hcub's original outputs before deduplication. Accept the same number of distinct label sets from each side, equal to the smaller supply. For every retained sequence on both sides, choose parents with the same span-first and delay-first functions. Trace back the rewritten outputs and remove newly unused gates. Give both sides the same ceiling on distinct mapped designs, capped by the original Hcub portfolio size and the smaller available rewritten portfolio. Select circuits by the same alternating proxy ranking. Area and delay may select different winners.
2. **Full search pools.** Permit all 32 Hcub trials including different orderings of the same labels and all originally enumerated exact label sets (at most 500 per pair). Apply the same two parent choices and identical mapping ceiling to both sides. This separates the effect of searching a larger input pool from the matched-label condition.
3. **Conservative baseline.** For each pair and metric, give Hcub the best of its original 32 seeded designs, its matched-label portfolio and its full-pool rewritten portfolio. Compare with the full-pool exact portfolio. This grants Hcub additional mapped designs.

All three comparisons report paired wins, ties and losses across every pair. The matched-label comparison is the primary comparison in this supplement. Reuse a previously mapped design only when its complete signed operations have the same SHA-256 identification. New designs must pass both mapped equivalence checks on every signed 16-bit input. These controls concern the 29 FFT arithmetic blocks. The two larger FIR comparisons are exploratory.

After obtaining the matched result, we fixed one transfer test before measuring any transfer outcomes. For each of the same 29 pairs, freeze each side's area winner in the matched resyn2 comparison (break ties by graph ID). Emit both circuits with the distributor's signed Verilog generator for the first corresponding 128-point table position. Lower the actual RTL with Icarus Verilog's BLIF backend and use the same ABC resyn2 script and Nangate45 library on both sides. Test both signed 32-bit outputs for every 16-bit input. Report all pairs, aggregate mapped area and paired delay. There is no selection on the new mapping results.
